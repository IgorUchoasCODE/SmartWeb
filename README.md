# SmartWeb — Informática e Redes

Projeto web desenvolvido em HTML, CSS e JavaScript.

## Como executar

Abra o arquivo `index.html` em um navegador.

## Estrutura

- `index.html` — contém a estrutura HTML, os estilos CSS e as funcionalidades JavaScript do projeto.

Não é necessário instalar dependências para executar a versão atual.
